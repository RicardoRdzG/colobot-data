## Glosario de Términos Unificados

| Término en inglés | Término en español | Notas |
|-------------------|--------------------|-------|
| Shooter | Disparador | No "Tirador" |
| Winged shooter | Disparador alado | Consistente con botfj |
| Winged grabber | Recogedor alado | Consistente con botgj |
| Power cell / battery | Celdas de energía | No "células" |
| Research center | Centro de Investigación | Con mayúscula inicial |
| Titanium | Titanio | Nombre propio |
| return value | Valor de retorno | Más preciso técnicamente |

## Instrucciones de Uso

1. **Trabajar en la rama `dev-spanish-review`** del submódulo `data/`
2. **Revisar archivo por archivo** usando Poedit
3. **Marcar como revisado** en este archivo cuando se complete la revisión
4. **Hacer commit por categorías** después de revisar grupos de archivos (ayuda, niveles, etc.)
5. **Mantener sync** con el repositorio principal actualizando el submodule ref

```bash
# Trabajar en el submódulo data
```
