\b;Ejercicio
Controla remotamente un robot esclavo sin usar un \l;puesto de intercambio de información\u object\exchange;. El robot debe pasar sobre las 6 cruces azules. Debes usar una \l;cadena\u cbot\string; para pasar las órdenes al bot esclavo. Esta cadena contiene la orden que el esclavo debe ejecutar, por ejemplo \c;"move(20)"\n;. Puedes ver que esta es la misma sintaxis usada en el lenguaje CBOT pero podríamos haber elegido cualquier otra sintaxis, por ejemplo algo como \c;"advance=20"\n;. La cadena será un miembro de clase \c;\l;static\u cbot\static;\n; que se usará para comunicar desde el maestro al esclavo.

Los dos actores principales de este ejercicio son:
1) El \l;recolector con ruedas\u object\botgr; sin paquete de energía y por lo tanto inmóvil. Este es el maestro que debes programar para que transmita órdenes al esclavo.
2) El esclavo \l;bot de práctica\u object\bottr; que ya está programado y simplemente espera órdenes del maestro.

\b;El esclavo
Primero debemos entender cómo funciona el programa del esclavo. La \l;clase\u cbot\class; \c;exchange\n; contiene el mecanismo para intercambiar las órdenes. Declaramos un miembro de clase \c;\l;static\u cbot\static;\n; \c;m_order\n; que contendrá la orden a ejecutar. La palabra \c;static\n; asegura que el miembro \c;m_order\n; se comparta entre todas las instancias de la \l;clase\u cbot\class; exchange.

\c;\s;\l;public\u cbot\public; \l;class\u cbot\class; exchange
\s;{
\s;	\l;static\u cbot\static; \l;private\u cbot\private; \l;string\u cbot\string; m_order = "";

\n;El método \c;put\n; será usado por el robot maestro para transmitir una orden. Mientras la cadena \c;m_order\n; no esté vacía, el esclavo no ha terminado la orden y el método \c;put\n; devolverá \c;false\n; y no hará nada.

\c;\s;	\l;synchronized\u cbot\synchro; \l;bool\u cbot\bool; put(string order)
\s;	{
\s;		if ( m_order == "" )
\s;		{
\s;			m_order = order;
\s;			return true;
\s;		}
\s;		else
\s;		{
\s;			return false;
\s;		}
\s;	}
\n;
Otro método \c;get\n; será usado por el esclavo para recuperar las órdenes. Este método devuelve la cadena contenida en \c;m_order\n; y la vacía, para que se pueda aceptar una nueva orden:

\c;\s;	\l;synchronized\u cbot\synchro; string get()
\s;	{
\s;		string ret = m_order;
\s;		m_order = "";
\s;		return ret;
\s;	}
\s;}
\n;
El programa principal del esclavo contiene una instancia de la clase \c;exchange\n; llamada \c;list\n;.

\c;\s;\l;extern\u cbot\extern; void object::Slave3( )
\s;{
\s;	exchange list();
\s;	string   todo;
\n;
El bucle \c;while\n; exterior dura para siempre. El bucle \c;while\n; interior espera una orden usando el método \c;get\n; de la clase \c;exchange\n;. Tan pronto como \c;get\n; devuelve una cadena no vacía, el bucle while se detiene.

\c;\s;	\l;while\u cbot\while; ( true )
\s;	{
\s;		\l;while\u cbot\while; ( true )
\s;		{
\s;			todo = list.get();
\s;			if ( todo != "" )  break;
\s;			wait(1);
\s;		}
\n;
Ahora hemos recibido la orden en la variable \c;todo\n;. Todo lo que tenemos que hacer es ejecutarla:

\c;\s;		if ( \l;strfind\u cbot\strfind;(todo, "move") == 0 )
\s;		{
\s;			move(\l;strval\u cbot\strval;(\l;strmid\u cbot\strmid;(todo,5)));
\s;		}
\s;		if ( strfind(todo, "turn") == 0 )
\s;		{
\s;			turn(strval(strmid(todo,5)));
\s;		}
\s;	}
\s;}
\n;
\b;El maestro
En el maestro escribimos una función llamada \c;SendOrder\n; que enviará una orden al esclavo:

\c;\s;void object::SendOrder(string order)
\s;{
\s;	exchange list();
\s;	
\s;	while ( list.put(order) == false )
\s;	{
\s;		wait(1);
\s;	}
\s;}
\n;
El bucle \c;while\n; espera hasta que una orden pendiente haya terminado, es decir, que el esclavo ha salido del método \c;get\n;.
Ahora el programa principal del maestro es muy simple:

\c;\s;extern void object::Remote3( )
\s;{
\s;	SendOrder("move(20)");
\s;	SendOrder("turn(90)");
\s;	SendOrder("move(20)");
\s;	SendOrder("turn(90)");
\s;	SendOrder("move(10)");
\s;	SendOrder("turn(90)");
\s;	SendOrder("move(10)");
\s;	SendOrder("turn(-90)");
\s;	SendOrder("move(10)");
\s;}
\n;
