\b;Ejercicio
Controla remotamente un robot esclavo sin usar un \l;puesto de intercambio de información\u object\exchange;. El robot debe pasar sobre las 6 cruces azules. Debes usar una variable \c;\l;static\u cbot\static;\n; para pasar las órdenes al bot esclavo.

Los dos actores principales de este ejercicio son:
1) El \l;recolector con ruedas\u object\botgr; sin paquete de energía y por lo tanto inmóvil. Este es el maestro que debes programar para que transmita órdenes al esclavo.
2) El esclavo \l;bot de práctica\u object\bottr; que ya está programado y simplemente espera órdenes del maestro.

\b;El esclavo
Primero debemos entender cómo funciona el programa del esclavo. La \l;clase\u cbot\class; \c;order\n; contiene dos miembros: \c;m_type\n; es la orden a ejecutar (mover o girar) y \c;m_param\n; es la distancia a mover o el ángulo de rotación:

\c;\s;\l;public\u cbot\public; \l;class\u cbot\class; order
\s;{
\s;	\l;int\u cbot\int;    m_type = \l;nan\u cbot\nan;;
\s;	\l;float\u cbot\float;  m_param;
\s;}
\n;
Una segunda \l;clase\u cbot\class; \c;exchange\n; contiene el mecanismo para intercambiar las órdenes. Declaramos un miembro de clase \c;\l;static\u cbot\static;\n; \c;m_order\n; que contendrá la orden a ejecutar. La palabra \c;static\n; asegura que el miembro \c;m_order\n; se comparte entre todas las instancias de la \l;clase\u cbot\class; exchange.

\c;\s;\l;public\u cbot\public; \l;class\u cbot\class; exchange
\s;{
\s;	\l;static\u cbot\static; \l;private\u cbot\private; order m_order = new order;
\n;
\n;El método \c;put\n; será usado por el robot maestro para transmitir una orden. Mientras \c;m_order\n; sea diferente de \c;\l;nan\u cbot\nan;\n;, el esclavo no ha terminado la orden y el método \c;put\n; devolverá \c;false\n; y no hará nada:

\c;\s;	\l;synchronized\u cbot\synchro; \l;bool\u cbot\bool; put(order a)
\s;	{
\s;		if ( m_order.m_type == nan )
\s;		{
\s;			m_order = a;
\s;			return true;
\s;		}
\s;		else
\s;		{
\s;			return false;
\s;		}
\s;	}
\n;
Otro método \c;get\n; será usado por el esclavo para recuperar las órdenes. Este método devuelve la orden a ejecutar:

\c;\s;	\l;synchronized\u cbot\synchro; order get()
\s;	{
\s;		return m_order;
\s;	}
\n;
Un tercer método \c;delete\n; será usado por el esclavo para indicar que la orden ha sido ejecutada:

\c;\s;	\l;synchronized\u cbot\synchro; void delete()
\s;	{
\s;		m_order.m_type = nan;
\s;	}
\s;}
\n;
El programa principal del esclavo contiene una instancia de la clase \c;exchange\n; llamada \c;list\n;. Ponemos () después de la palabra \c;list\n; para crear una instancia de la clase \c;exchange\n;.

\c;\s;\l;extern\u cbot\extern; void object::Slave3( )
\s;{
\s;	exchange list();
\s;	order    todo;
\n;
El bucle \c;while\n; externo dura para siempre. El bucle \c;while\n; interno espera una orden usando el método \c;get\n; de la clase \c;exchange\n;. Tan pronto como \c;get\n; devuelve un valor diferente de \c;nan\n;, el bucle while se detiene.

\c;\s;	\l;while\u cbot\while; ( true )
\s;	{
\s;		\l;while\u cbot\while; ( true )
\s;		{
\s;			todo = list.get();
\s;			if ( todo.m_type != nan )  break;
\s;			wait(1);
\s;		}
\n;
Ahora hemos recibido la orden en la variable \c;todo\n;. Todo lo que tenemos que hacer es ejecutarla:

\c;\s;		if ( todo.m_type == 1 )
\s;		{
\s;			move(todo.m_param);
\s;		}
\s;		else if ( todo.m_type == 2 )
\s;		{
\s;			turn(todo.m_param);
\s;		}
\s;		else
\s;		{
\s;			message("Orden desconocida");
\s;		}
\n;
Tan pronto como termina la ejecución de la orden, debemos llamar al método \c;delete\n; para que el maestro sepa que se puede enviar otra orden:

\c;\s;		list.delete();
\s;	}
\s;}
\n;
\b;El maestro
En el maestro escribimos una función llamada \c;SendOrder\n; que enviará una orden al esclavo:

\c;\s;void object::SendOrder(float order, float param)
\s;{
\s;	exchange list();
\s;	order    todo();
\s;	
\s;	todo.m_type = order;
\s;	todo.m_param = param;
\s;	
\s;	while ( list.put(todo) == false )
\s;	{
\s;		wait(1);
\s;	}
\s;}
\n;
El bucle \c;while\n; espera hasta que una orden pendiente haya terminado, es decir, que el esclavo haya salido del método \c;get\n; y el método \c;delete\n; haya sido llamado.
Ahora el programa principal del maestro es muy simple:

\c;\s;extern void object::Remote4( )
\s;{
\s;	SendOrder(1, 20);  // move(20);
\s;	SendOrder(2, 90);  // turn(90);
\s;	SendOrder(1, 20);  // move(20);
\s;	SendOrder(2, 90);  // turn(90);
\s;	SendOrder(1, 10);  // move(10);
\s;	SendOrder(2, 90);  // turn(90);
\s;	SendOrder(1, 10);  // move(10);
\s;	SendOrder(2,-90);  // turn(-90);
\s;	SendOrder(1, 10);  // move(10);
\s;}
\n;
