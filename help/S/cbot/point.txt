\b;Tipo \c;point\n; (punto)
Las variables de este tipo contienen las coordenadas de un punto en el espacio. Este tipo se compone de tres valores que representan las coordenadas \c;x\n;, \c;y\n; y \c;z\n;.
\c;x\n; y \c;y\n; corresponden al lugar en el suelo. El eje \c;x\n; positivo mira hacia el este, el eje \c;y\n; positivo mira hacia el norte.
El valor \c;z\n; corresponde a la altitud sobre el nivel del mar. 

Si quieres declarar una variable de tipo punto, puedes escribir: 
\c;
\s;	point a (10, 20, 30);
\n;
También puedes establecer la variable tomando un valor tras otro:
\c;
\s;	point b;
\s;	b.x = 10;
\s;	b.y = 20;
\s;	b.z = 30;
\n;
Con estos ejemplos, se cumple la siguiente \l;condición\u cbot\cond;:
\c;
\s;	if ( a == b )
\s;	{
\s;	}
\n; 
La siguiente declaración :
\c;
\s;	point c (4, 7);
\n;
Es equivalente a:
\c;
\s;	point c;
\s;	c.x = 4;
\s;	c.y = 7;
\s;	c.z = 0;
\n;
