\b;Instrucción \c;strmid\n;
Extrae una subcadena de una longitud determinada a partir de una posición determinada de una cadena.

Sintaxis:
\s;\c;strmid ( cadena, pos, longitud );\n;

\t;pos: \c;\l;int\u cbot\int;\n;
El índice del primer carácter que se incluirá en la subcadena extraída.

\t;longitud: \c;\l;int\u cbot\int;\n;
Número de caracteres que se extraerán.

Ejemplos:
\s;\c;	string s = strmid("abcdef", 1, 2);  // s es "bc"
\s;	string s = strmid("abcdef", 4, 5);  // s es "ef"
\s;	string s = strmid("abcdef", 9, 2);  // s es ""
\n;
