\b;Instrucción \c;extern\n;
La instrucción \c;extern\n; determina la \l;función\u cbot\function; que actúa como programa principal de un robot. El nombre de la función declarada con \c;extern\n; aparecerá en la lista de programas en la esquina inferior izquierda de la pantalla.
\c;
\s;extern void object::Acribillar( )
\s;{
\s;	while ( true )
\s;	{
\s;		fire(1);
\s;		turn(10);
\s;	}
\s;}
\n;
Si el programa contiene otras funciones, solo la función principal debe ir precedida de \c;extern\n;.
\c;
\s;extern void objeto::Cuadrado( ) 
\s;{
\s;	for ( int i=0 ; i<4 ; i++ )
\s;	{
\s;		Linea(10);
\s;	}
\s;}
\s;
\s;void object::Linea(float dist)
\s;{
\s;	move(dist);
\s;	turn(90);
\s;}
\n;
