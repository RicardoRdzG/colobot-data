\b;Instrucción \c;deflag\n;
Sintaxis:
\s;\c;deflag ( );\n;

Elimina una \l;bandera de color\u object\flag; delante del \l;rastreador\u object\botsr;.

\t;Valor devuelto: \c;\l;int\u cbot\int;\n;
Normalmente un error detiene el programa. Puedes evitar que el programa se detenga en errores usando la instrucción \c;\l;errmode\u cbot\errmode;(0)\n;. Si se produce un error, se devuelve un valor diferente de cero por \c;deflag();\n;.
\c;== 0 \n;bandera eliminada
\c;!= 0 \n;no se pudo eliminar la bandera
