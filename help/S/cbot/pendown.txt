\b;Instrucción \c;pendown\n; (bajar lápiz)
Sintaxis:
\s;\c;pendown ( color, ancho );\n;
La instrucción \c;pendown(); \n;  indica al bot que baje el lápiz  para que comience a dibujar.

\t;color: \c;\l;int\u cbot\int;\n; (valor predeterminado: \c;Black\n; (negro))
\l;Nombre del color\u cbot\colors;.

\t;ancho: \c;\l;float\u cbot\float;\n; (valor predeterminado: \c;0.5\n;)
Ancho del lápiz. El ancho no puede ser superior a \c;1.0\n; ni inferior a \c;0.0\n;. Si se pasa un valor superior, el ancho será el máximo posible, y si se pasa un valor inferior, el ancho será el mínimo posible.

\t;Valor devuelto: \c;\l;int\u cbot\int;\n;
Normalmente un error detiene el programa. Puedes evitar que el programa se detenga ante errores usando la instrucción \c;\l;errmode\u cbot\errmode;(0)\n;. Se devuelve un valor diferente de cero si se produjo un error mediante \c;pendown();\n;.
\c;== 0 \n;El lápiz está ahora abajo
\c;!= 0 \n;La instrucción no funcionó
