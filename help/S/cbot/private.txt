\b;Instrucción \c;private\n; (para especialistas)
Este es un modificador de acceso para miembros \l;de clase\u cbot\class;. No se puede acceder a los miembros privados fuera de la definición de clase.

\t;Ejemplo
\c;
\s;public class MiClase
\s;{
\s;	int    b;                // publica por defecto
\s;	public int a;            // tambien publica 
\s;	private point position;  // privada
\s;}
\s;void Test()
\s;{
\s;	MiClase item;
\s;	item.a = item.b = 12;      // ok
\s;	message( item.position );  // this is an error
\s;}
\n;
