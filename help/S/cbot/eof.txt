\b;Instrucción \c;eof\n;
Comprueba si un archivo abierto ha llegado al final. Se trata de un método de la clase \c;\l;file\u cbot\file;\n;; por lo tanto, no puedes escribir \c; eof()\n;, sino solo \c;handle.eof()\n;:
\c;
\s;	if ( handle.eof() ) 
\n;
Ejemplo:
\c;
\s;	while (no handle.eof() )
\s;	{
\s;		s = handle.readln();
\s;	}
\n;
